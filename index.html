Care Advisor: an LLM agent hospital staff can trust

Cincinnati Children's Hospital Medical Center · May 2026 to present

Hospital staff needed fast answers about patient flow and capacity. I built the service behind it and kept one rule: Python does the math, the model only explains it.

  • Built a FastMCP Python server with eleven forecasting and capacity tools over hospital data in Microsoft Fabric SQL.
  • Replaced nested query objects with flat, typed Pydantic schemas, so the model makes clean structured tool calls and every input is validated.
  • Deployed a FastAPI gateway in Docker to Azure inside a private network, with token based sign in and CI running ruff, mypy, tests, and the image build.
  • Ran a data audit that found three production bugs, including a NULL versus text filter that returned empty results with no error.
  • Built evaluation test sets and scoring, Langfuse tracing on every run, and agent memory through Hindsight.

Clinical NLP: prior authorization readiness classifier

Natural Language Processing course project · 2026

I fine tuned BiomedBERT on 5,000 de identified MIMIC IV records and compared three BERT models against a TF IDF baseline. I used leakage prevention, weighted loss, threshold tuning, and fp16 mixed precision on GPU.

The result was near random AUC with a majority class bias. I reported that plainly instead of leaning on a single F1 score, because a model that looks good on one metric can still be useless.
